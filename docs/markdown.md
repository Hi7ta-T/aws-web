# マークダウンの頻出コマンド
1. 見出し<br>
   #：大見出し（タイトルなど）<br>
   ##：中見出し（セクション、部門別など）<br>
   ###：小見出し（詳細内容）<br>
<br>
2. 箇条書き…「-」か「*」<br>
* 要点を簡単にまとめるときに使用<br>

3. 画像…「![説明内容]()」<br>

4. リンク…「[]」か「()」<br>
   他のファイルや参考資料<br>

5. 強調したい部分…「*」か「**」<br>
   * 使いすぎると見えづらくなるので注意<br>

6. コード…「`」<br>
   コードとして認識させたい時に使用（ファイルパスなど）<br>

7. 区切り線…「---」<br>
   --- セクションの区切りとして使用可能 ---<br>

8. 引用…「>」<br>
   > 引用したい点を強調できる<br>
